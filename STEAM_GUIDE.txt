[h1]Save editor: money, loans, reputation, staff[/h1]

[b]Unofficial fan tool for single-player. Use at your own risk. Not affiliated with the developers.[/b]

An open-source tool that lets you change, in a save file:
[list]
[*] [b]Money balance[/b]
[*] [b]Loans[/b] (remaining amount and interest)
[*] [b]Reputation[/b] (level 1-14 and XP progress)
[*] [b]Staff[/b] (refill stamina, wages, XP)
[/list]
It lists your saves, makes a backup before every change, verifies the result, and can restore backups. The full source code is public, so you can read exactly what it does.

[h2]Before you start[/h2]
[olist]
[*] Close the game completely.
[*] Turn off Steam Cloud for the game: right-click the game > Properties > General > untick "Keep game saves in the Steam Cloud". Otherwise Steam may restore your old save.
[*] (Optional) Make your own copy of the save folder. Paste this into the Explorer address bar:
[code]%LOCALAPPDATA%\Ski-E-O\SaveGames[/code]
[/olist]

[h2]How to use it[/h2]
[olist]
[*] Start the tool.
[*] [b]Step 1:[/b] pick your save. The list shows one row per resort (its newest save) with the current balance. Tick "Show all save slots" to see every autosave and manual save.
[*] [b]Step 2:[/b] change something. Type a new balance and click [b]Apply[/b], or use the [b]Loans...[/b], [b]Reputation...[/b] or [b]Staff...[/b] buttons. Every change shows a confirmation first.
[*] Start the game and load that save.
[/olist]
Screenshots of each step are in the "Screenshots" section below.

[h2]Money balance[/h2]
Type a whole number, for example [b]2000000[/b], or click a quick-amount button, then [b]Apply[/b].

[h2]Loans[/h2]
Click [b]Loans...[/b]. Each loan shows its original amount, what is left, and the monthly interest. Type new values (any remaining amount from 0, interest from 0% to 100% per month), or use [i]Remaining -> 0 for all[/i] and [i]Interest -> 0% for all[/i].
A loan with [b]0 remaining[/b] stays on the list with a "pay off" button. Click it in the game to remove the loan; it costs nothing. A loan with 0% interest only costs its principal.

[h2]Reputation[/h2]
Click [b]Reputation...[/b] and pick a level (1-14) and the XP progress inside that level. XP restarts at 0 after a level-up. XP needed to level up:
[code]1  Small Hill               280
2  Hidden Gem              1,050
3  Local Favorite          2,300
4  Powder Stash            4,950
5  Regional Hotspot        9,050
6  Rising Star            18,700
7  Destination Resort     35,000
8  Powder Mecca           65,000
9  Premier Mountain      130,000
10 Elite Resort          230,000
11 Prestigious Destination 350,000
12 World Class           600,000
13 Iconic Destination    900,000
14 Legendary Resort      (maximum)[/code]
Going down a level may lock buildings you unlocked earlier. At the top level the game no longer shows the exact XP. If you enter XP at or above the level-up amount, the game will most likely level up when you load the save.

[h2]Staff[/h2]
Click [b]Staff...[/b]. You see each role (liftie, groomer, ski patrol, maintenance) with headcount, average wage, XP and stamina. Choose everybody or one role, then any of:
[list]
[*] [b]Refill stamina to 100%[/b]
[*] [b]Daily wage[/b]: set to an amount, or scale by a percent (never below 1)
[*] [b]XP[/b]: enough XP makes a promotion available in the game
[/list]
Wages and XP stay as set; stamina drains normally while employees work.

[h2]Undo / restore a backup[/h2]
Every change is backed up automatically to:
[code]Documents\Ski-E-O Save Editor Backups[/code]
In the tool open [b]Tools > Restore a backup...[/b], pick the backup and confirm. You can also use [b]Tools > Open backups folder[/b] and copy the files back into the SaveGames folder yourself. Backups from older versions are still listed.

[h2]Good to know[/h2]
[list]
[*] Very large numbers can overflow. The balance maximum is 2,147,483,647, but 1-10 million is safer.
[*] The game has several save slots per resort; the list shows the newest one by default. Tick "Show all save slots" if you load an older one.
[*] Tested with save version 51.102. After a game update the tool may refuse to edit, which is intentional.
[*] Never share your save file publicly: it contains your Steam ID.
[/list]

[h2]Problems?[/h2]
If the game does not show the change: make sure the game was closed while editing, Steam Cloud is off, and you loaded the edited slot. Restore a backup if anything looks wrong. Please report issues on the GitHub page (https://github.com/TPrazak/ski-e-o-save-editor) with the message the tool showed.
